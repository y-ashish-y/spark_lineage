# NYC Yellow Taxi — 100-row sample

`yellow_trip_sample.csv` is a deterministic, 100-row synthetic dataset
generated by `generate_sample.py`. The schema mirrors the public
[NYC TLC Yellow Taxi trip record](https://www.nyc.gov/assets/tlc/downloads/pdf/data_dictionary_trip_records_yellow.pdf)
column definitions, so any code written against the official release will
parse this file too.

The CSV:

- has exactly **100 data rows** (101 lines counting the header),
- is regenerated with `python generate_sample.py` (seed `20260101`),
- exists solely to keep the demo small, offline, and license-safe.

If you want to swap in real data, drop a `yellow_trip_sample.csv` file
with the same schema in this directory and re-run the notebooks.
